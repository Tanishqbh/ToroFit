# ToroFit

A basic fitness tracking Python package.

## Installation

```bash
pip install torofit
```

Or install from source:

```bash
git clone https://github.com/Tanishqbh/ToroFit.git
cd ToroFit
pip install -e .
```

## Quick Start

```python
import torofit

print(torofit.greet("Athlete"))
# Hello, Athlete! Welcome to ToroFit.
```

## Documentation

Full documentation is available at [torofit.readthedocs.io](https://torofit.readthedocs.io).

To build the docs locally:

```bash
pip install sphinx
cd docs
make html
```

## Development

Run the tests:

```bash
pip install pytest
pytest
```
