Usage
=====

Basic usage
-----------

Import the package and call :func:`torofit.greet`:

.. code-block:: python

   import torofit

   print(torofit.greet("Athlete"))
   # Hello, Athlete! Welcome to ToroFit.

You can also call it without arguments:

.. code-block:: python

   from torofit import greet

   print(greet())
   # Hello, World! Welcome to ToroFit.
