Installation
============

Requirements
------------

* Python 3.9 or later
* pip

Install from PyPI
-----------------

.. code-block:: bash

   pip install torofit

Install from source
-------------------

Clone the repository and install in editable mode:

.. code-block:: bash

   git clone https://github.com/Tanishqbh/ToroFit.git
   cd ToroFit
   pip install -e .
